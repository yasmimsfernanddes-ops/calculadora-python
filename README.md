# Calculadora em Python

Projeto de uma calculadora simples feita em Python, executada no terminal.

## Funcionalidades

- Soma, subtração, multiplicação e divisão
- Tratamento de divisão por zero
- Tratamento de entradas inválidas
- Menu de opções que se repete até o usuário escolher sair

## Arquivos

| Arquivo | Descrição |
|---|---|
| `calculadora.py` | Código da calculadora |

## Como executar

Requisito: Python 3 instalado.

```bash
python calculadora.py
```

## Tecnologias

- Python 3
- Git e GitHub (versionamento)
